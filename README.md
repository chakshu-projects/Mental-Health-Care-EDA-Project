# Mental-Health-Care-EDA-Project

## 1) Understanding the Dataset   
This dataset studies how social media use affects the mental health of teenagers. It includes daily habits like social media hours, sleep, stress, anxiety, and physical activity. The goal is to understand if high social media use is linked with problems like stress, anxiety, and depression.  

## 2) Dataset Description  
  -  Daily Social Media Hours  
  -  Platform Usage
  -  Screen Time Before Sleep
  -  Academic Performance
  -  Stress Level
  -  Depression Label
## 3) Data Preprocessing  
  -  Checked for missing values and data inconsistencies.
  -  Handled null values in selected columns.
  -  Verified data types and feature distributions.
  -  Prepared data for exploratory data analysis and visualization.  
## 4) Visualizations Used   
  -  **Bar Charts**: to compare categorical variables and frequency distributions.
  -  **Line Charts**: to identify trends and patterns across variables.
  -  **Correlation**: Heatmap to measure relationships between numerical features.
  -  **Count Plots**: to analyze class distributions and categorical features.
  -  **Pie Charts**: to compare the relationship between different dimensions.
## 5) Key Insights 
  -  Higher social media usage is associated with increased stress and addiction levels.
  -  Reduced sleep hours may contribute to poorer mental health outcomes.
  -  Physical activity appears to have a positive impact on overall well-being.
  -  Social interaction levels influence stress and anxiety patterns.
  -  Depression cases represent a small portion of the dataset but remain an important area for analysis.
## 6) Tools & Technologies Used

  -  Numpy

  -  Seaborn
  -  Jupyter Notebook
## 7) Conclusion  
The data analysis indicates that social media usage has a noticeable impact on teenagers’ mental health and daily lifestyle patterns. Platforms like Instagram were found to be the most commonly used, while higher screen time showed a slight association with increased stress, anxiety, and depression levels. The study also suggests that excessive social media engagement may affect sleep quality and reduce healthy social interactions.
